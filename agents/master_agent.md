# Master AI Agent

The Master AI Agent is the central reasoning engine for the entire Aiva System.  
All Sub‑Agents depend on it. All inbound and outbound messages—customer‑facing or internal—flow through it.  
It enforces the business’s Voice Profile, Communication Profile, Channel Rules, Rewrite Preferences, and Safety Rules.

The Master Agent does NOT perform business‑specific logic.  
It performs communication intelligence only.

---

## Core Responsibilities

- Rewrite all messages using the business’s Voice Profile.
- Apply Communication Profile rules for clarity, empathy, and professionalism.
- Apply Channel Rules for SMS, email, webchat, and phone scripts.
- Apply Rewrite Preferences for structure, tone, and safety.
- Enforce Safety Rules and detect risky or unclear language.
- Accept override instructions from Sub‑Agents.
- Produce clean, safe, channel‑formatted output.
- Maintain consistent communication across all Sub‑Agents and channels.

---

## Input Contract

The Master Agent receives a full context object defined in `context.schema.json`.

### Required Fields

- `business_id`
- `agent_id`
- `timestamp`
- `channel`
- `original_message`
- `voice_profile`
- `communication_profile`
- `channel_rules`
- `rewrite_preferences`
- `sub_agent_overrides`

### Optional Metadata

- `lead_id`
- `customer_id`
- `conversation_id`
- `source`

---

## Output Contract

The Master Agent returns a structured object:
{
"rewritten_message": "",
"safety_flags": [],
"metadata": { "channel": "", "agent": "", "business_id": "" }
}


- `rewritten_message` is the final, safe, formatted message.
- `safety_flags` lists any detected risks or issues.
- `metadata` is passed through for logging and routing.

---

## Processing Pipeline

The Master Agent executes the following steps in order:

1. **Apply Safety Rules**  
   - Detect risky, unclear, or non‑compliant language.  
   - Add safety flags.  
   - Rewrite if necessary.

2. **Apply Rewrite Preferences**  
   - Improve clarity, structure, tone, and professionalism.

3. **Apply Voice Profile**  
   - Match tone, style, phrasing, and brand language.

4. **Apply Communication Profile**  
   - Enforce empathy, clarity, and professionalism rules.

5. **Apply Channel Rules**  
   - Format for SMS, email, webchat, or phone scripts.

6. **Apply Sub‑Agent Overrides**  
   - Modify tone, structure, urgency, or behavior based on the Sub‑Agent.

7. **Return Final Output**  
   - Clean, safe, formatted message.

---

## Relationship to Sub‑Agents

Sub‑Agents do NOT rewrite messages themselves.

Instead, they:

- Provide purpose‑specific overrides  
- Provide templates  
- Provide structure rules  
- Provide tone adjustments  
- Provide urgency or escalation instructions  

The Master Agent:

- Executes the rewrite  
- Applies all profiles and rules  
- Ensures consistency across all Sub‑Agents  

This architecture ensures:

- Modularity  
- Reusability  
- Zero customization per SMB  
- Universal behavior across industries

## Design Principles

- **Universal** — Works for all SMBs and industries.  
- **Modular** — Sub‑Agents plug in without modifying core logic.  
- **Reusable** — No per‑client customization required.  
- **Low‑Lift** — Minimal developer time to deploy.  
- **Consistent** — All messages follow the same communication standards.  
- **Safe** — Built‑in safety and escalation detection.

## Notes for Developers

- Do NOT modify the Master Agent for client‑specific logic.  
- All client‑specific behavior must be handled through:  
  - Templates  
  - Profiles  
  - Sub‑Agent overrides  
  - Routing logic  

The Master Agent must remain universal and stable.
